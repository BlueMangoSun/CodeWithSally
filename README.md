## 🌟 Overview

**Code with Sally** transforms abstract programming concepts into tangible visual outcomes. Players travel along a constellation map of coding checkpoints, guided by real-world women pioneers in STEM. 

In our featured **For Loops** module, players join **Dr. Wangari Maathai** (founder of the Green Belt Movement) to write Python loops that plant trees and restore digital ecosystems in real-time.

### 🎯 Key Target Tracks
* **Best Overall:** Zero-dependency, lightweight, responsive browser application featuring custom SVG art and interactive state management.
* **Best Female Empowerment:** Highlights female role models in STEM—such as Katherine Johnson, Grace Hopper, Marie Curie, and Wangari Maathai—with interactive narrative cards.
* **Most Sustainable:** Connects core code structures directly to environmental stewardship and tree restoration metrics.
* **Best Beginner:** Scaffolded learning progression with real-time syntax checking, helpful diagnostic error hints, and visual code prompts.

---

## ✨ Features

- **Interactive Constellation Map:** Navigate through 9 core programming concept checkpoints styled after cosmic stars.
- **Live Pixel-Art Simulation:** Watch code run in real time with animated SVG graphics (e.g., dynamic tree growth in the meadow).
- **Custom Cursor & Visual FX:** Animated astronaut cursor, custom SVG starfields, and particle celebrations.
- **Scaffolded Progression:** Multi-stage learning loops that move beginners from guided templates to open sandbox exploration.
- **Instant Diagnostic Feedback:** In-editor syntax error callouts and contextual coding hints.
