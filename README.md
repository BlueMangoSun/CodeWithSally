# ✦ Code with Sally: Cosmic Code Quest
Made for Girl Hoo Hacks Hackathon 2026

> An interactive, web-based coding game designed to introduce young learners—especially girls—to Python programming fundamentals through historical STEM pioneers and environmental sustainability simulations.

---

## 🌟 Overview

**Code with Sally** transforms abstract programming concepts into tangible visual outcomes. Players travel along a constellation map of coding checkpoints, guided by women pioneers in STEM. 

In our featured **For Loops** module, players join **Dr. Wangari Maathai** (founder of the Green Belt Movement) to write Python loops that plant trees and restore digital ecosystems in real-time.

---

## ✨ Features

- **Interactive Constellation Map:** Navigate through 9 core programming concept checkpoints styled after cosmic stars.
- **Live Pixel-Art Simulation:** Watch code run in real time with animated SVG graphics (Ex. Planting trees).
- **Step-By-Step Learning and Exploration Tasks:** Multi-stage learning loops that move beginners from guided templates to open sandbox exploration.
- **Instant Feedback:** In-editor syntax error callouts and contextual coding hints.
- **Real-World Impact:** Prompts players to discover environmental initiatives near them (like local tree-planting non-profits).
- **Flying Astronaut Cursor:** Sally Ride acts as their intergalactic guide as they complete each checkpoint. 

---
## 🚀 Checkpoints & Curriculum

1. **Print** (Sally Ride) – Display messages
2. **Variables** (Katherine Johnson) – Store and save values
3. **Collections** (Lise Meitner) – Lists, strings, and indexed access
4. **For Loops** (Wangari Maathai) – Repeat actions and plant trees
5. **While Loops** (Annie Easley) – Conditional repetition
6. **If Statements** (Grace Hopper) – Conditional logic
7. **Functions** (Dorothy Vaughan) – Reusable code blocks
8. **Dictionaries** (Mary Jackson) – Key-value pairs
9. **Classes** (Marie Curie) – Object-oriented structures
